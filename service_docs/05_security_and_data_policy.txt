Nimbus Stack — Security & Data Policy

Data Encryption
All data is encrypted in transit using TLS 1.3 and at rest using AES-256. Encryption keys are rotated automatically every 90 days.

Data Residency
By default, workspace data is stored in the United States. Enterprise customers can request EU data residency at no additional cost, subject to a one-time migration process that takes up to 5 business days.

Backups
Full workspace backups are taken every 6 hours and retained for 30 days. Point-in-time restoration is available to Enterprise customers upon request; Starter and Growth customers can request a restore from the most recent nightly backup only.

Two-Factor Authentication
2FA is available on all plans via authenticator app (TOTP). SMS-based 2FA is not supported due to security concerns around SIM-swapping attacks. Enterprise customers can additionally enforce SSO/SAML login for all members.

Data Export
Workspace Admins can export all project, task, and comment data as CSV or JSON at any time from Workspace Settings > Data > Export. Exports include full history and are generated asynchronously, with a download link emailed once ready (typically within 10 minutes).

Data Deletion
When a workspace is deleted, all associated data is permanently purged from production systems within 30 days and from backup systems within 90 days. This cannot be expedited or reversed once initiated.

Compliance
Nimbus Stack is SOC 2 Type II certified. We do not currently offer HIPAA-compliant workspaces; healthcare organizations handling PHI should not store such data in Nimbus Stack at this time.
